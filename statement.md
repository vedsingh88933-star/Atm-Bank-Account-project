# Problem Statement
Traditional banking requires physical presence or complex web interfaces. This project provides a lightweight, secure, and intuitive Command Line Interface (CLI) for users to perform core banking operations without relying on external network requests or heavy GUIs.

# Scope of the project
The system handles basic account authentication, deposit and withdrawal calculations, and transaction logging using local JSON storage for data persistence.

# Target users
Individuals needing a fast, terminal-based utility to simulate or track basic financial transactions and balances.

# High-level features
- Secure PIN-based authentication.
- Real-time balance checking.
- Cash withdrawal with automated overdraft protection.
- Cash deposit.
- Transaction history tracking.
